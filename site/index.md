# Make the change. Keep what matters.

WP MCP Server connects Claude, Cursor and Codex to WordPress. Preview useful content and settings edits, preserve explicit requirements, and keep local change history.

## What you can do

- Inspect a registered site and its stored values.
- Preview supported content, metadata and option edits before applying them.
- Turn explicit corrections into rules scoped to the correct site and field.
- Check supported edits against active rules before writing.
- Save prior values on supported edits and read results back.

Correction rules require configuration; chat history does not automatically become policy. Stored-value checks do not replace visual or interaction testing. Plugin recognition does not establish native editing support.

## Install

Core is self-hosted and MIT licensed. Bring an AI client that can reach its authenticated MCP endpoint and connect WordPress using SSH with WP-CLI or the companion plugin.

[Installation guide](https://github.com/cgallic/wpguard-mcp/blob/main/docs/getting-started.md)
