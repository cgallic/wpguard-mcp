Questions

Pricing FAQ

What counts as a governed site?

A site you register with WPGuard, tracked for packets, policy decisions, and evidence. Each site configured in WPGuard Cloud counts toward the plan limit.

What happens when I outgrow my plan?

Additional-site rates are shown per month in the table above. Agency Pro and Platform exist so growing agencies aren't stuck paying overage indefinitely.

Does Cloud ever hold my WordPress credentials?

No. Cloud never holds SSH private keys, WordPress application passwords, or companion-plugin API keys. It never holds reusable local MCP bearer tokens either — under any plan. See the full trust architecture for exactly what Cloud may and must never hold.

Why not just use the free tier forever?

You can use Core without a subscription. The open-source tools, local history and correction checks remain available on your own installation.

What's the difference between Community and Cloud?

Core runs the WordPress operations and stores local history. Cloud is a separate paired workspace for packet records and approval decisions. Cloud adds shared packet history and approval decisions to the WordPress operations and local history in Core.
